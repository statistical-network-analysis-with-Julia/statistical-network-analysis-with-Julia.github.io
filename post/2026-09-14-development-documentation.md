# Finding your way through the development documentation

{{post_date}}

The development documentation now connects the umbrella guides and all
15 package reference sites through shared navigation. There are three useful
starting points:

- [Get started](/getting-started/) prepares a Julia environment and introduces
  a first analysis using the Florentine marriage network.
- [The package directory](/packages/) lets you search by package, method or
  data type, with supported scope beside each documentation link.
- [Worked examples](/examples/) connect network structure, binary models,
  interaction sequences and network panels to their interpretation.

The package introductions and quickstarts explain where to go next, while the
[capability tables](/capabilities/) record estimator conventions and the scope
of reference comparisons. The [R migration guide](/migration/) describes
important differences from statnet and RSiena.

Version **0.2.0 remains unreleased**. Use the documented source-checkout workflow,
keep your package revisions and Manifest, and inspect the relevant estimator's
diagnostics before interpreting a fit.
