The ecosystem

Find the right package.

Sixteen packages connect network data, descriptive analysis and statistical modelling. Start with the question you want to answer, then follow the documentation for your data and estimator. Fifteen are listed here; the sixteenth, Relevent.jl, is the event-model engine underneath Revel.jl and is used through it.

Development documentation. These pages describe the unreleased 0.2.0 workspace. Set up the source checkouts and review supported capabilities before fitting a model.

15 packages

Network data

NetworkCore.jl

Create and exchange attributed networks, including directed and two-mode data.

The foundation for shared data, missingness and result contracts.

Documentation →Source
Descriptive analysis

SNA.jl

Measure centrality, cohesion and equivalence; test dyadic associations with QAP.

Binary defaults are explicit; weighted and missing-data policies vary by routine.

Documentation →Source
Exponential random graphs

ERGM.jl

Model binary ties with network statistics, then simulate networks and diagnose fit.

R’s default estimator: the exact MPLE for dyad-independent formulas, MCMLE otherwise. Inspect convergence.

Documentation →Source
Count-valued networks

ERGMCount.jl

Model nonnegative integer edge values with a choice of reference distribution.

MCMLE for dyad-dependent formulas, as in R; improper models are flagged and refused downstream. Two-mode networks are unavailable.

Documentation →Source
Egocentric data

ERGMEgo.jl

Estimate network models from sampled egos and their reported relationships.

Inference depends on ego sampling, population assumptions and convergence.

Documentation →Source
Multiple relations

ERGMMulti.jl

Represent layers of relationships and fit terms that connect those layers.

Layers of one network, with R’s default estimator and coefficient labels. Models over several networks are unavailable.

Documentation →Source
Ranked relationships

ERGMRank.jl

Fit models to actors’ rankings with swap pseudolikelihood or rank MCMC-MLE.

Rank MCMC-MLE by default; the swap MPLE is a pseudo-likelihood with bootstrap inference.

Documentation →Source
Custom model terms

ERGMUserterms.jl

Develop, validate and benchmark your own ERGM statistics and change statistics.

A development toolkit for extending ERGM.jl.

Documentation →Source
Tie formation and persistence

TERGM.jl

Fit separable temporal ERGMs to observed network transitions.

CMLE for dyad-dependent formulas, as in tergm, and the exact CMPLE otherwise. EGMME is unavailable.

Documentation →Source
Actor-oriented models

Siena.jl

Estimate stochastic actor-oriented models for networks observed at multiple waves.

Method of Moments with RSiena’s default effects; RSiena-named effects are checked against RSiena. No likelihood or Bayesian estimation.

Documentation →Source
Ordinal relational events

REM.jl

Compare each interaction with all or sampled eligible dyads in its risk set.

Sampling and tied-event conventions affect the likelihood and interpretation.

Documentation →Source
Event effects and diagnostics

Revel.jl

Specify network effects, covariates and their interactions for event models, then check the fit.

Ordinal or exponential timing fits. No random effects; effect names differ across R packages.

Documentation →Source
Dynamic network data

DynamicNetworks.jl

Store activity spells and changing attributes, then extract network snapshots.

Choose time units, observation windows and activity semantics explicitly.

Documentation →Source
Temporal network analysis

TSNA.jl

Find time-respecting paths, reachability and statistics across active networks.

Active-actor defaults and time units are documented; missing dyads need a policy.

Documentation →Source
Network animation

NDTV.jl

Lay out dynamic networks and export animations of changing relationships.

Rendering and export requirements are documented for each output format.
